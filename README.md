# Суммаризация новостей: RoBERTa против LLM (CNN/DailyMail)

По тексту новостной статьи нужно получить краткое резюме из 3–4 предложений. Сравниваются три подхода в одинаковых условиях: дообученная экстрактивная RoBERTa (выбирает предложения статьи по схеме BertSumExt), открытая Qwen3.6-35B-A3B локально через LM Studio и GPT-6 Luna через OpenAI API. Обе LLM работают без дообучения, с одинаковым промптом. Lead-3 (первые три предложения статьи) — точка отсчёта.

[Открыть ноутбук в Colab](https://colab.research.google.com/github/l1can13/llm-summarizer/blob/master/lr2_summarization.ipynb) — открывается с сохранёнными результатами.

## Результаты

Тест — 1 000 случайных статей официального test, одни и те же для всех моделей. ROUGE — F1 со стеммингом, BERTScore — roberta-large с перемасштабированием, всё в процентах. Задержка — медиана на одну статью: RoBERTa на RTX 4070 (bf16) и i7-12700F (fp32), Qwen — RTX 4070 + CPU.

| Модель | ROUGE-1 | ROUGE-2 | ROUGE-L | BLEU | BERTScore | Задержка |
|---|---|---|---|---|---|---|
| Lead-3 | 39.57 | 17.05 | 35.93 | 11.38 | 24.87 | – |
| **RoBERTa-base** | **43.29** | **20.48** | **39.71** | **14.24** | **30.90** | **22 мс** / 0.71 с на CPU |
| Qwen3.6-35B-A3B (Q4_K_M) | 39.04 | 13.45 | 35.43 | 8.41 | 28.80 | 14.35 с |
| GPT-6 Luna | 39.97 | 15.04 | 36.08 | 8.37 | 27.53 | 1.68 с |

RoBERTa лучше по всем метрикам и в 76–650 раз быстрее LLM. Обе LLM уступают даже Lead-3 по ROUGE-2 и BLEU: они перефразируют (52–58 % новых биграмм против 48 % в эталоне), а эталоны CNN/DailyMail в основном повторяют слова статьи. GPT-6 Luna пишет длиннее запрошенного (82 слова вместо около 50) и стоит $0.14 за 1 000 статей.

## Сравнение с опубликованными результатами

Схема RoBERTa повторяет BertSumExt. Результаты авторов взяты из статьи [Liu, Lapata, 2019](https://arxiv.org/abs/1908.08345), таблица 2.

| Система | ROUGE-1 | ROUGE-2 | ROUGE-L |
|---|---|---|---|
| Lead-3, авторы | 40.42 | 17.62 | 36.67 |
| BertSumExt (BERT-base), авторы | 43.25 | 20.24 | 39.63 |
| BertSumExt (BERT-large), авторы | 43.85 | 20.34 | 39.90 |
| Lead-3 | 39.57 | 17.05 | 35.93 |
| **RoBERTa-base** | **43.29** | **20.48** | **39.71** |

RoBERTa-base на уровне BertSumExt (BERT-base), обучение — одна эпоха. У авторов полный test (11 490 статей) и другая реализация ROUGE, поэтому сравнение ориентировочное.

Условия: RoBERTa — 1 эпоха на 283 823 статьях, AdamW (lr 5e-5, weight decay 0.01), батч 16, разогрев 10 % + линейное затухание, bf16, 61 мин на RTX 4070. LLM — temperature 0, до 256 новых токенов, рассуждения отключены, промпт выбран из двух вариантов на 50 статьях validation.

## Структура

- `lr2_summarization.ipynb` — эксперимент: данные → анализ → обучение RoBERTa → генерация LLM → оценка;
- `src/` — код: данные и очистка, экстрактивная модель, клиенты LLM, метрики, графики;
- `outputs/` — таблицы, графики, логи обучения и все ответы LLM (`generations/*.jsonl`).

## Запуск

Датасет [CNN/DailyMail 3.0.0](https://huggingface.co/datasets/abisee/cnn_dailymail) (~840 МБ) ноутбук скачивает сам в `../datasets/cnn_dailymail/`.

```
python -m venv .venv
.venv\Scripts\pip install torch==2.14.0 --index-url https://download.pytorch.org/whl/cu130
.venv\Scripts\pip install -r requirements.txt ipykernel
```

Ключ OpenAI задаётся в файле `.env` строкой `OPENAI_API_KEY=...`, в репозиторий файл не входит. Qwen запускается через LM Studio (модель `qwen/qwen3.6-35b-a3b`), ноутбук сам загружает и выгружает её командой `lms`. Ответы LLM сохраняются построчно, поэтому прерванную ячейку можно запустить снова. В Colab LM Studio недоступен, но ответы обеих LLM уже лежат в `outputs/generations`.
